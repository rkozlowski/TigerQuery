DocFX generates this reference from the public and protected APIs, source
files, and XML documentation comments in the three published library projects.
Choose a namespace to browse its types:

- [ItTiger.TigerQuery](xref:ItTiger.TigerQuery) — parsing primitives and
  sqlcmd modes
- [ItTiger.TigerQuery.Engine](xref:ItTiger.TigerQuery.Engine) — engine
  configuration, execution, and results
- [ItTiger.TigerQuery.Events](xref:ItTiger.TigerQuery.Events) — messages,
  batch lifecycle events, result sets, and prepared-plan information
- [ItTiger.TigerQuery.Core](xref:ItTiger.TigerQuery.Core) — connection

- [ItTiger.TigerQuery.Core.Encryption](xref:ItTiger.TigerQuery.Core.Encryption)

The `ItTiger.TigerSqlCmd` application, tests, and internal implementation types
are intentionally outside this reference.
